# API Testing & Performance Pipeline (JavaScript & Jest)

An automated backend testing and performance pipeline built using JavaScript, Axios, and Jest to validate RESTful APIs and response times.

## Tech Stack
- **Language:** JavaScript (Node.js)
- **Testing Framework:** Jest
- **HTTP Client:** Axios

## Features
- Automated GET and POST endpoint validation.
- Real-time API response time performance benchmarking (< 1000ms assertions).
- Structured assertions for status codes and response payload schemas.
